              Настройка на backend
              Провайдер и модель выбираются приватными переменными окружения. Mini App не принимает API-ключ.
              
            

            

              Как подключить
              
    
                
  1. Создай API key в кабинете провайдера.
    2. 
                
  2. Сохрани его в приватной переменной окружения backend, не в Mini App.
    3. 
                
  3. Перезапусти backend и нажми “Проверить backend”. Ключ никогда не возвращается в браузер.
    4.

              Как подключить локальную модель
              
    
                
  1. Ollama должна быть запущена на этом компьютере.
    2. 
                
  2. Backend принимает только localhost и не отправляет данные наружу.
    3. 
                
  3. Модель получает ограниченный снимок рассчитанных данных без прав на запись.
